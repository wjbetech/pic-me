## Agent Brief

**Category:** bug
**Summary:** Multiple Choice images intermittently show the spinner indefinitely instead of the animal photo

**Current behavior:**
Starting a Multiple Choice round sometimes leaves the `DisplayCard` image in its `isImageLoading` spinner state forever. The game code at `src/components/MultiChoice/MultiChoice.tsx` loads the dataset via `useAnimals` and preloads the chosen animal's image. Two suspect paths: (1) the 20 `plus.unsplash.com/premium_photo` entries in the in-game dataset (homepage was decoupled to `homePhotos` in #40 but games still use the full dataset) return watermarked/blocked responses that never resolve `onload`/`onerror`, and (2) the `useAnimals` loader may race with the session-restore path.

**Verification performed during triage:**
- **Redundancy check:** searched `src/data/homePhotos.ts` vs `src/data/animals*.json` — homepage now exclusively uses the curated set, but `MultiChoice` still draws from the full dataset including premium previews. No existing fix covers in-game premium images.
- **Prior rejection:** checked `.out-of-scope/` — no prior `wontfix` for premium image replacement.
- **Repro hint:** start Multiple Choice repeatedly; observe `src/utils/openAnswer.ts` preload path and `src/components/MultiChoice/DisplayCard` `onLoad`/`onError` handlers.

**Desired behavior:**
Every round eventually shows either the animal image or the "No image available" fallback — never a perpetual spinner. Premium preview URLs should either be replaced with freely licensed originals (like the homepage set) or gracefully degrade to the fallback after a timeout, as the persistence layer already does for session restore.

**Key interfaces:**
- `useAnimals` hook — what it currently returns vs what it should return for premium entries
- `MultiChoice` image state (`currentImage`, `isImageLoading`, `Animal.images[0].url`) — where the loading contract should guarantee termination

**Acceptance criteria:**
- [ ] Root cause identified and documented in a comment (premium URL vs loader vs image state)
- [ ] Repro steps or log evidence attached
- [ ] Fix guarantees termination to image or fallback within a bounded time
- [ ] Spinner/placeholder states remain (no blank flashes)

**Out of scope:**
- Replacing the entire animal dataset (scope to MC image loading only)
- Homepage photo set (already decoupled)
